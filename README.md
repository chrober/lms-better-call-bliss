# Bliss 'Em All

Bliss 'Em All is the planned Lyrion Music Server plugin for auditable playlist
optimization powered by Bliss. It will depend on a compatible BlissMixer
installation for `bliss.db`, the learned matrix, captured scoring settings,
and the platform's `bliss-playlist-optimizer` executable.

This repository is a Phase 0 scaffold and is **not installable yet**. It does
not contain a `plugin.xml`, repository manifest, or executable bundle, so it
cannot be mistaken for a functional release.

The plugin will own LMS menus, preferences, background jobs, optional semantic
providers, reports, and atomic playlist persistence. The native optimizer will
remain network-free.
