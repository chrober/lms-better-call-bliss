# Plugin package

This directory contains the first installable, read-only vertical slice. It
contributes **Bliss 'Em All** to Applications/My Apps, reports live capability
status, lists real saved playlists, captures BlissMixer's Adaptive settings and
repeat windows, starts a native reorder preview, and renders the proposed
sequence.

The milestone deliberately disables playlist creation. It proves the complete
UI-to-native-preview path before persistence is added.
