# Plugin package

This directory contains the installable `0.2.0` full UX shell. It contributes
**Bliss 'Em All** to Applications/My Apps and informational playlist/track
context entries. The one connected execution path selects a real saved
playlist, captures BlissMixer's Adaptive settings and repeat windows, starts a
native reorder-only preview, and renders the proposed sequence.

All other modes and mutations are visibly marked **Not connected yet**. The
milestone deliberately disables playlist creation. See `docs/UX_STATUS.md` in
the repository root for the exact working/partial/future feature matrix.
