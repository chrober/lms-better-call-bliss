Source and behavior

Optimize may move the existing tracks. Preserve keeps every source track as an immutable anchor in its current order and permits additions only inside the existing gaps.

Preserving the source order without requesting any possible additions would leave the playlist unchanged. Choose an addition mode with a non-zero target.
Automatic additions

Used only by Add automatically. It may legitimately add zero tracks when no transition exceeds the trigger or no candidate improves it.

Plugin default: [% blissemall_defaults.max_added_tracks %]
Plugin default: [% blissemall_defaults.trigger_percent %]

Only transitions above this percentile are considered. Acoustic improvement and repeat constraints still have to pass. Optional Last.fm/ListenBrainz evidence is not connected yet; this slice falls back to local Bliss evidence.

Exact additions

Used only by Add exactly N tracks. The result is all-or-nothing: the preview succeeds with exactly this many unique additions or fails without offering a partial playlist.

Choose a playlist to see the current limit.

This connected slice inserts at most one track inside each internal source-track transition. Opening and closing additions are not enabled.

Mixing strategy
BlissMixer default: [% blissemall_defaults.seed_limit %]
BlissMixer default: [% blissemall_defaults.learned_percent %]

For each directional transition, Adaptive scoring uses up to this many immediately preceding tracks. For a bridge C between A and B it evaluates history ending in A to C, then the updated history ending in C to B. A value of 1 reduces this to A to C and C to B; variance-based dynamic weighting starts once at least two context tracks are available.

These values are passed to the optimizer request for this preview.

Repeat constraints

Use 0 to disable a constraint. For a single-artist playlist, set Artist look-back to 0.

BlissMixer default: [% blissemall_defaults.artist_window %]
BlissMixer default: [% blissemall_defaults.album_window %]
BlissMixer default: [% blissemall_defaults.track_window %]
Advanced search effort

Used only when source tracks may be reordered. Each deterministic attempt starts from another candidate order and applies local improvements. More attempts may find a better route but increase processing time. Zero still evaluates the built-in fixed starts.

Output after accepting a preview

Create optimized copy is connected after a successful preview. Overwrite source remains unavailable.

Leave blank to generate a name from the playlist filename. Existing names are never overwritten; an automatic name uses the next free suffix such as (2).
