The transition-quality threshold is a distance rank, not a similarity percentage. Lower values are stricter: they cause more direct transitions to be searched and require better neighboring legs in Automatic destination routes. At 30, for example, a leg is acceptable only when no more than about 30% of the relevant comparison population is acoustically closer. Cautious mode may search even below the threshold when acoustic models strongly disagree. If no route reaches the target, a bridge is used only when it improves the cautious direct result by at least one percentile point; otherwise the direct destination is retained and reported. Exact uses the same adjacent-path objective for its fixed count. Current BlissMixer scoring, context, and repeat settings plus the Last.fm settings below are captured when the action starts.



Last.fm guidance

Every job can override these Better Call Bliss defaults. LastMix prepares the Last.fm evidence; request failures fall back to Bliss. Similar-track guidance is a bounded boost for acoustically suitable local candidates. Similar-artist guidance can either pursue a target share or add a bounded boost that competes with the local listening signals. Zero disables the corresponding channel.
