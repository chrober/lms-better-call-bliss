Bliss me there...

The track context action starts a read-only destination-route preview immediately. These defaults replace the full Extras editor for that quick action; every job still records the exact values it used.

The difficult-transition percentile above is the quality target used by Automatic destination routing. Automatic first looks for the shortest route that meets it; if none does, it returns the smoothest repeat-safe route available within the maximum intermediate-track budget and reports the achieved result. Current BlissMixer scoring, context, and repeat settings plus the Last.fm settings below are captured when the action starts.
