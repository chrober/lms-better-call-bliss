Source and behavior

Optimize may move the existing tracks. Preserve keeps every source track as an immutable anchor in its current order and permits additions only inside the existing gaps.

Preserving the source order without requesting any possible additions would leave the playlist unchanged. Choose an addition mode with a non-zero target.
Grow from these seeds

Used only by Grow from these seeds. Every source song is kept exactly once. The complete source playlist remains the fixed musical reference while local analyzed tracks are selected, so newly added songs cannot pull later choices away from the original taste. The complete seed-plus-addition membership is then reordered for transition flow.

Choose a playlist to see the addition count.
Automatic additions

Used only by Add automatically. It may legitimately add zero tracks when no transition exceeds the trigger or no candidate improves it.

Plugin default: [% bettercallbliss_defaults.max_added_tracks %]
Plugin default: [% bettercallbliss_defaults.trigger_percent %]

Only transitions above this percentile are considered. Acoustic improvement and repeat constraints still have to pass. Optional Last.fm guidance can help rank eligible choices; ListenBrainz comes later.

Variation and Last.fm guidance
0 = strict best match; higher values explore a wider top-quality pool.

Variation is applied after the selected similarity strategy, so it also applies to future Static and Forest strategies. Leave the seed blank for a new result on each run; enter a previous result seed to reproduce it.

[% UNLESS bettercallbliss_lastmix_available %]Requires the LastMix plugin to be installed and enabled.[% END %]
Plugin default: [% bettercallbliss_defaults.lastfm_track_guidance_percent %]
Plugin default: [% bettercallbliss_defaults.lastfm_artist_guidance_percent %]

Better Call Bliss asks LastMix for tracks and artists related to the complete original playlist. For an individual gap, track evidence from both neighboring songs is strongest, followed by one neighbor, similar artists, and the original artist collection as fallback. These percentages set bounded influence, not ownership of the choice: candidates must still be local, repeat-safe, and pass Bliss acoustic checks. Zero ignores that evidence type. Network/API failures fall back to Bliss without failing the job. Last.fm is not used for fixed-membership Reorder only jobs.

Exact additions

Used only by Add exactly N tracks. The result is all-or-nothing: the preview succeeds with exactly this many unique additions or fails without offering a partial playlist.

Choose a playlist to see the current limit.

This connected slice inserts at most one track inside each internal source-track transition. Opening and closing additions are not enabled.

Mixing strategy
Current BlissMixer setting: [% bettercallbliss_defaults.seed_limit %]
Current BlissMixer setting: [% bettercallbliss_defaults.learned_percent %]

For each directional transition, Adaptive scoring uses up to this many immediately preceding tracks. For a bridge C between A and B it evaluates history ending in A to C, then the updated history ending in C to B. A value of 1 reduces this to A to C and C to B; variance-based dynamic weighting starts once at least two context tracks are available.

These values are passed to the optimizer request for this preview.

Repeat constraints

Use 0 to disable a constraint. For a single-artist playlist, set Artist look-back to 0.

Current BlissMixer setting: [% bettercallbliss_defaults.artist_window %]
Current BlissMixer setting: [% bettercallbliss_defaults.album_window %]
Current BlissMixer setting: [% bettercallbliss_defaults.track_window %]
Advanced search effort

Used only when source tracks may be reordered. Each deterministic attempt starts from another candidate order and applies local improvements. More attempts may find a better route but increase processing time. Zero still evaluates the built-in fixed starts.

Output after accepting a preview

Choose what happens after you accept a successful preview. Creating a copy is safest; overwriting the source requires a separate confirmation after the preview.

Leave blank to generate a name from the selected playlist only when you create the copy. Existing names are never overwritten; an automatic name uses the next free suffix such as (2).

Requires explicit confirmation after preview; the source playlist file and LMS catalog order are replaced.

Replace queue clears the selected player's queue, adds the generated order, and starts only when this checkbox is checked. Append adds the result at the end. Play next inserts it after the current song.
