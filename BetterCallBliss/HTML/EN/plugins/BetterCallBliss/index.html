Preserving the source order without requesting any possible additions would leave the playlist unchanged. Choose an addition mode with a non-zero target.
Grow from these seeds

Used only by Grow from these seeds. Every source song is kept exactly once. The complete source playlist remains the fixed musical reference while local analyzed tracks are selected, so newly added songs cannot pull later choices away from the original taste. The complete seed-plus-addition membership is then reordered for transition flow.

Choose a playlist to see the addition count.
Automatic additions

Used only by Add automatically. It may legitimately add zero tracks when no transition exceeds the trigger or no candidate improves it.

Plugin default: [% bettercallbliss_defaults.max_added_tracks %]
Plugin default: [% bettercallbliss_defaults.trigger_percent %]

Only transitions above this percentile are considered. Acoustic improvement and repeat constraints still have to pass. Optional Last.fm guidance can help rank eligible choices; ListenBrainz comes later.

Exact additions

Used only by Add exactly N tracks. The result is all-or-nothing: the preview succeeds with exactly this many unique additions or fails without offering a partial playlist.

Choose a source to see the current limit.

This mode inserts at most one track inside each internal source-track transition. Opening and closing additions are not enabled.

Target track count

Used only by Reach target track count. Enter the desired final number of tracks. Better Call Bliss calculates the required additions and may enable an opening or closing slot only when the internal gaps alone cannot reach the target.

Choose a source to see the current target range.
Double track count

Used only by Double track count. This preset asks for one added local track per original source track, yielding exactly twice as many tracks. If internal gaps provide only S - 1 slots, Better Call Bliss may also use one opening or closing slot.

Choose a source to see the calculated final size.

Variation
0 = strict best match; higher values explore a wider top-quality pool.

Variation is applied after the selected similarity strategy, so it also applies to future Static and Forest strategies. Leave the seed blank for a new result on each run; enter a previous result seed to reproduce it.

Last.fm guidance
[% UNLESS bettercallbliss_lastmix_available %]Requires the LastMix plugin to be installed and enabled.[% END %]
Plugin default: [% bettercallbliss_defaults.lastfm_track_guidance_percent %]
Plugin default: [% bettercallbliss_defaults.lastfm_artist_guidance_percent %]

Better Call Bliss asks LastMix for tracks and artists related to the complete original playlist. For an individual gap, track evidence from both neighboring songs is strongest, followed by one neighbor, similar artists, and the original artist collection as fallback. These percentages set bounded influence, not ownership of the choice: candidates must still be local, repeat-safe, and pass Bliss acoustic checks. Zero ignores that evidence type. Network/API failures fall back to Bliss without failing the job.

Mixing strategy
Current BlissMixer setting: [% bettercallbliss_defaults.seed_limit %]
Current BlissMixer setting: [% bettercallbliss_defaults.learned_percent %]

For each directional transition, Adaptive scoring uses up to this many immediately preceding tracks. For a bridge C between A and B it evaluates history ending in A to C, then the updated history ending in C to B. A value of 1 reduces this to A to C and C to B; variance-based dynamic weighting starts once at least two context tracks are available.

Current BlissMixer strategy: [% bettercallbliss_capability.algorithm | html %]. These values are passed to the optimizer request for this preview. Static uses BlissMixer's four metric sliders expanded to the 23 Bliss audio features. Adaptive can run without a learned matrix; in that case multi-track contexts use variance and one-track contexts fall back to the static BlissMixer weights.
